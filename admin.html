Admin Panel - Jangkauan WiFi

👋 Cara Penggunaan

  1. Gunakan panel Daftar Router untuk menambah atau menghapus titik akses WiFi.
  2. Klik Simpan Perubahan untuk menerapkan update ke aplikasi pengguna secara langsung.
  3. Gunakan panel Simulasi Koneksi User untuk menentukan Router mana yang "sedang terhubung" oleh user.
  4. Ini akan membuat Router tersebut menyala kuning di peta jangkauan user.
